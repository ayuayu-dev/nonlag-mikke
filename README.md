# のんらぐみっけ！ 🎮📶🐈

> ゲーマーのための「建物別」実測Ping値・回線レビュー共有マップアプリ

---

## 📖 サービス概要

オンライン対戦ゲーム（格闘ゲームやFPSなど）をプレイするゲーマーが、引っ越しや物件探しの際に最も重要視する「マンション・アパート単位での実測Ping値や回線品質」を地図上で直感的に探し、共有できるWebサービスです。

### 開発の目的
実務を意識したモダンWebアプリケーション（Laravel 12 × Vue 3 / Inertia.js）の開発実践、地図ピンや位置情報データのパフォーマンスチューニング、およびAWSクラウドインフラへの本番デプロイ・運用を見据えたポートフォリオとして開発を行っています。

### イメージキャラクターデザイン案

#### デザインコンセプト
- **モチーフ**: 猫の「ラグドール」× 通信の「ラグ（Lag）」
- **コンセプト**:
  - オンラインゲームの大敵である通信遅延（ラグ）のない「ノンラグ（Non-Lag）」な住環境を一緒に探してくれるナビゲーター。
  - 穏やかで人懐っこい猫種「ラグドール」をモチーフに、青い瞳とふんわりとした毛並みで、回線選びに悩むゲーマーに安心感と親しみやすさを届けるシンボルとしてデザインしました。
- **名前**: 検討中

## 🎯 主な機能

### 未認証（ゲスト）
- [ ] エントランス（検索トップ）画面
  - 市区町村・最寄り駅・キーワードによるクイック検索
  - ログイン不要での物件・Ping値マップ閲覧
- [ ] ユーザー新規登録（メール認証機能付き）
- [ ] ログイン / ログアウト

### 認証済み（ユーザー）
- [ ] ダッシュボード
- [ ] マイページ機能
  - プロフィール情報更新
  - パスワード変更
  - アカウント削除
- [ ] 回線レビュー・実測Ping値投稿機能
  - 建物名・住所・部屋タイプ（戸建て/マンション）入力
  - 契約プロバイダ / 回線タイプ選択
  - 実測Ping値（ms）・上り/下り速度の登録
  - スピードテスト結果スクショ画像の選択 & アップロード
  - 画像フォーマット対応 (JPEG / PNG / WebP)
- [ ] インタラクティブ地図（Leaflet）画面
  - 建物ごとのピン留め表示
  - Ping値に応じたピンの色分け表示（高速：青 / 標準：黄 / 要注意：赤）
  - ピン選択時の物件詳細モーダル（レビュー一覧表示）
